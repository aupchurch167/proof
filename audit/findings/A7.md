# A7 — Billing

**Skip.** The app does not charge. There is no Stripe (or other PSP) dependency, webhook, customer portal, or invoice object.

`Organization.plan` is an enum (`FREE|STARTER|UNLIMITED`) default FREE (`schema.prisma:48-52,74`). Limits are a static map (`config/plans.js`). Settings UI: “Billing is not yet self-serve — to change plans, contact us” (`client/src/pages/Settings.jsx:195-201`). `PUT /api/organization` cannot set `plan` (`organization.js:28-35`). Enforcement is `enforcePlanLimit` (fails open — A3-10) plus import-loop checks.

No entitlements cache, no webhook signature, no dunning. When billing is added, revisit this file; do not invent Stripe work now.
